These are the exact launch and verification paths used for the project. The runbook starts with baseline connectivity, because a firewall cannot be judged against an already broken network.

Launch sequence

From environment to full verification.

Run these from /home/suresh/project/dynamic-firewall. The controller uses the existing ../.venv; Mininet's test runner uses Ubuntu's system Python.

Step 01 · Prepare

Install network packages and check Python.

Ubuntu shellprerequisites
sudo apt-get install mininet openvswitch-switch
sudo systemctl start openvswitch-switch
cd /home/suresh/project/dynamic-firewall
bash scripts/bootstrap.sh

The bootstrap script pins old Ryu build tooling and applies its Eventlet WSGI compatibility fix inside the virtual environment.

Step 02 · Controller

Keep Ryu open in its own terminal.

Terminal 1no root
cd /home/suresh/project/dynamic-firewall
bash scripts/run_controller.sh

Confirm TCP 6653 and 8080 are listening. The REST API is local to the machine.

Step 03 · Unit verification

Check rule construction before network use.

Terminal 2no root
../.venv/bin/python -m unittest discover -s tests -v

Six tests cover validation, both drop matches, exact deletion, barrier-gated state, and reconnect replay.

Step 04 · Real network test

Run Mininet and OVS as root.

Terminal 2root required
sudo /usr/bin/python3 tests/run_integration.py

Creates and removes the topology; refuses to block if baseline ping fails; writes the report, raw evidence, and timing.

Manual inspection

See each transition yourself.

The automated runner follows this same order, with assertions and evidence capture added.

01

Start the three-host topology

sudo mn --custom topology.py --topo firewalltopo --switch ovsk,protocols=OpenFlow13 --controller remote,ip=127.0.0.1,port=6653

02

Prove the baseline

At mininet>, run nodes, net, and pingall. Stop and diagnose if the all-host result is not 0% loss.

03

Apply the block and inspect s1

curl -X POST http://127.0.0.1:8080/firewall/block/10.0.0.2, then sudo ovs-ofctl -O OpenFlow13 dump-flows s1.

04

Prove selective denial

At mininet>, run h1 ping -c 3 h2, h3 ping -c 3 h2, and h1 ping -c 3 h3. Expect 100%, 100%, and 0% loss respectively.

05

Remove policy and recover

curl -X POST http://127.0.0.1:8080/firewall/unblock/10.0.0.2. Verify the drops disappear from s1; then ping h2 and run pingall again.

Troubleshooting record

Issues found and how they were resolved.

These are actual compatibility and execution problems encountered while building and testing the project.

Ryu 4.34 build failed on modern setuptools

Ryu's setup hook calls easy_install.get_script_args, which newer setuptools removed. The bootstrap script pins setuptools==58.0.4 and installs Ryu with --no-build-isolation inside the Python 3.11 environment.

Ryu imported Eventlet's removed ALREADY_HANDLED symbol

The published Ryu release predates this Eventlet API change. Bootstrap patches Ryu's installed WSGI integration to use getattr(eventlet.wsgi, 'ALREADY_HANDLED', None), matching upstream compatibility behavior. The controller then started and served REST requests.

An older Eventlet release failed on Python 3.11

Eventlet 0.30.2 tried to modify the immutable TimeoutError type. The working environment uses Eventlet 0.41.3 and dnspython 2.9.0 with the Ryu compatibility patch.

Mininet initially refused to start

Mininet requires root to create network namespaces and interfaces. The first unprivileged attempt exited before topology creation. After root authorization, the full network test passed.

If baseline, blocking, or recovery fails on a future run

Check ss -ltnp for ports 6653 and 8080, ovs-vsctl get bridge s1 protocols, and ovs-ofctl -O OpenFlow13 dump-flows s1. Verify priority 0 NORMAL before blocking, two priority 100 drops while blocked, and no drops after unblocking. Use sudo mn -c only if a previous Mininet run left stale interfaces.

Honest boundaries

What this implementation does not claim.

The lab demonstrates real IPv4 policy enforcement. It is intentionally not a production firewall or intrusion-detection system.

Protocol scope

IPv4 only

ARP, IPv6, and other EtherTypes remain outside the rule. A blocked client can still participate in ARP. The match covers IPv4 generally, but the executed payload test used ICMP pings, not separate TCP/UDP transfers.

Identity

IP, not authenticated host

The policy matches addresses without binding them to a switch port or MAC. A host that spoofs an allowed address could evade this demonstration design.

Availability

In-memory policy

A controller restart loses its desired blocked set and cleans stale firewall cookies on reconnect. Errors or timeouts can leave partial switch state; inspect OVS and reconnect for reconciliation.

Security operations

Local administrative API

REST binds to loopback and has no authentication. Automatic new-TCP-attempt detection was not implemented; counting arbitrary packets would not meet that feature's stated semantics.
