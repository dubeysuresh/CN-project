01

One broadcast domain

All clients share 10.0.0.0/24. ARP and direct L2 forwarding can be observed without a router hiding the firewall effect.

02

One enforcement point

A single switch table makes it clear that h2 isolation comes from OpenFlow rules, not a host configuration change.

03

Two unaffected peers

h1→h3 gives a control path while h2 is blocked. A successful ping here proves the policy is selective.

04

Explicit DPID and version

The controller accepts DPID 1 and the bridge uses OpenFlow 1.3, removing ambiguity about where FlowMods go.

Component responsibilities

Control plane versus data plane.

Keeping policy decisions and packet enforcement separate is the core SDN design choice in this project.

◈

Ryu controller

Owns the blocked-client set, validates API requests, sends FlowMods, waits for barrier replies, and replays policy when s1 reconnects.

CONTROL PLANE
◇

Open vSwitch

Compares each frame with its OpenFlow table. Priority-100 matches drop h2 IPv4; priority-0 NORMAL handles ordinary L2 forwarding.

DATA PLANE
⌘

Mininet hosts

Generate real ping packets in separate namespaces. Their success or loss tests switch behavior, not merely the API response.

Packet theory

ARP still works. IPv4 can be dropped.

ARP and IPv4 are different EtherTypes. The firewall matches only 0x0800 frames, so address resolution remains possible even while h2's IPv4 packets are denied.

Before the block

Normal L2 switching

h1 learns h2's MAC with ARP. Its ICMP Echo Request enters s1 and reaches the priority-0 NORMAL action. OVS forwards it to h2. The reply follows the same path in reverse.

Flow tablepriority 0
match: any frame
instruction: OUTPUT:NORMAL
During the block

Priority wins

h1's ARP may still reach h2. The subsequent IPv4 Echo Request matches ipv4_dst=10.0.0.2 at priority 100 and is dropped before normal forwarding.

Flow tablepriority 100
match: eth_type=0x0800,
       ipv4_dst=10.0.0.2
instruction: none → drop
The design does not claim to block ARP, IPv6, or spoofed identities. See known limits for the precise scope.
